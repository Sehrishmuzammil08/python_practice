# 💻 Introduction to Programming

## 📌 1. What is Programming?

Programming is the **process of giving instructions to a computer** so it can perform specific tasks.

---

## 📌 2. What is a Program?

A **program** is a set of `step-by-step instructions written in a programming language that tells a computer what to do.`

### Examples
-  Calculator applications
-  Websites and web applications
-  Robots and smart devices
-  Problem-solving software

---

## 📌 3. Why Do We Need Programming?

Computers cannot think on their own. They only follow instructions given by programmers.

Programming helps us:

-  Automate repetitive tasks
-  Solve complex problems quickly
-  Develop software, websites, and mobile apps
-  Create games
-  Control hardware and embedded systems
-  Without programming, computers would be useless machines.
  
---

## 📌 4. What is a Programming Language?

A **programming language** is a language used to communicate with computers.

Since computers understand only **binary (0s and 1s)**, programming languages act as a bridge between humans and computers.

### Popular Programming Languages

-  Python
-  Java
-  C
-  C++
-  JavaScript
-  C#

---

## 📌 5. High-Level vs Low-Level Languages

| High-Level Languages | Low-Level Languages |
|-----------------------|---------------------|
| Easy to learn | Difficult to learn |
| Human-readable | Close to machine language |
| Less hardware knowledge required | Requires hardware knowledge |
| Slower than low-level | Faster and more efficient |
| Examples: Python, Java, C++, JavaScript | Examples: Machine Language, Assembly Language |

---

## 📌 6. Compiler vs Interpreter

### Compiler

- Translates the **entire program** at once.
- Creates an executable file.
- Shows errors after compilation.

**Examples**
- C
- C++
- Java (partially)

### Interpreter

- Translates and executes code **line by line**.
- No executable file is created.
- Errors appear immediately.

**Examples**
- Python
- JavaScript

---

## 📌 7. Hardware vs Software

### Hardware

Physical components of a computer.

Examples:
- CPU
- RAM
- Hard Disk
- Keyboard
- Mouse
- Monitor

### Software

Programs that run on hardware.

Examples:
- Windows
- Linux
- Google Chrome
- Microsoft Word
- Mobile Apps
- Games

---

## 📌 8. Program Execution Process

```
Programmer
      │
      ▼
Write Code
      │
      ▼
Compiler / Interpreter
      │
      ▼
Computer Executes Instructions
      │
      ▼
Output
```

---

## 📌 9. Real-Life Analogy

Programming is like giving instructions to a person.

 **Unclear**

> Make tea.

 **Clear**

1. Boil water
2. Add tea leaves
3. Pour into a cup

Computers require clear and precise instructions.

#  Summary

- Programming means giving instructions to a computer.
- A program is a set of instructions written in a programming language.
- Programming languages help humans communicate with computers.
- High-level languages are easier to learn than low-level languages.
- Compilers translate the whole program, while interpreters execute code line by line.
- Hardware is the physical part of a computer, while software consists of programs.
- Programming is used in almost every modern technology.
