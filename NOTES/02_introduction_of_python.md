#  Introduction to Python

Python is one of the most popular and beginner-friendly programming languages. It is easy to learn, powerful, and widely used in many fields such as web development, data science, artificial intelligence, automation, and cyber security.

---

# 📌 1. What is Python?

Python is a **high level programming language that is famous for being easy to read & write.**

It is known for its **simple syntax**, which makes it easy to read and write.

### Features of Python

-  Easy to learn and use
-  Simple and readable syntax
-  Open-source and free
-  Cross-platform (Windows, Linux, macOS)
-  Large standard library
-  Supports Object-Oriented Programming (OOP)
-  Interpreted language

---

# 📌 2. Short History of Python

- Python was created by **Guido van Rossum**.
- Development started in **1989**.
- The first official version (**Python 0.9.0**) was released in **1991**.
- The language was named **Python** after the British comedy show **"Monty Python's Flying Circus"**, not after the snake.
- Today, Python is maintained by the **Python Software Foundation (PSF)**.
